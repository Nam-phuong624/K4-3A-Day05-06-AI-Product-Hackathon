2017: Transformer & Cơ chế Tự chú ý

Trước năm 2017, các mô hình xử lý ngôn ngữ truyền thống như RNN hoặc LSTM xử lý dữ liệu theo chuỗi tuần tự từng từ một, dẫn đến hiện tượng nghẽn cổ chai và khó huấn luyện song song.

Transformer là bước ngoặt vì nó cho mô hình hiểu ngôn ngữ theo cách linh hoạt hơn: mỗi từ có thể nhìn sang những từ quan trọng khác trong cả câu nhờ cơ chế Attention (Tự chú ý), thay vì chỉ đi tuần tự từng bước.

Cơ chế này trở thành nền móng kỹ thuật cốt lõi cho GPT, BERT và toàn bộ làn sóng LLM hiện đại.

* Lưu ý: Thuật toán PPO (Proximal Policy Optimization) thuộc bài học RLHF chuyên sâu, không có trong nội dung bài học Day 1 này.

Workflow patterns — đủ cho hầu hết bài toán

— Ba mô hình cơ bản theo Anthropic · Building Effective Agents (2024)

1. Prompt Chaining: Chia task thành chuỗi bước tuần tự, có gate kiểm tra giữa các bước (VD: Viết outline → check → viết bài). Ý nghĩa: đổi độ trễ lấy độ chính xác.

2. Routing: Phân loại input → đưa vào nhánh chuyên biệt, tối ưu từng loại riêng (VD: CS query → FAQ / refund / kỹ thuật). Ý nghĩa: câu dễ đi model rẻ, câu khó đi model mạnh.

3. Parallelization: Chạy song song rồi tổng hợp (sectioning), hoặc chạy nhiều lần lấy vote (VD: Guardrail + response đồng thời). Ý nghĩa: vote để giảm rủi ro một đầu ra sai.

* NGUYÊN TẮC ANTHROPIC: Luôn ưu tiên giải pháp đơn giản nhất; chỉ tăng độ phức tạp khi thực sự cần thiết. 3 mô hình cơ bản đã đủ đáp ứng hầu hết bài toán thực tế.

Kỹ thuật Delimiters & Cô Lập Dữ Liệu Input

Khi xây dựng Agent trong production, lỗi phổ biến nhất là để dữ liệu đầu vào trộn lẫn trực tiếp với chỉ dẫn của hệ thống, gây ra rủi ro Prompt Injection và Context Bleed.

<instruction>Chỉ xử lý văn bản nằm trong thẻ <user_query></instruction> <user_query>Bao bọc mọi dữ liệu từ User, API responses, hoặc DB queries</user_query>

Bao bọc mọi dữ liệu từ User, API responses, hoặc DB queries vào trong các thẻ định danh rõ ràng giúp mô hình phân định ranh giới giữa lệnh thực thi và dữ liệu thô.

Nguyên tắc Tính nhất quán: Duy trì đồng nhất một loại thẻ phân tách xuyên suốt toàn bộ prompt để mô hình hình thành khuôn mẫu nhận diện ổn định.
